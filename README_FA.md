# SNI spoof (بدون روت) مثل RstaNG

روی نسخه‌ی جدید شما (که موتور را در پروسه‌ی جدا `:snispoof` اجرا می‌کند) ساخته شده؛ آن معماری دست نخورده مانده.

- **صفحه‌ی تنظیمات واحد**: تنظیمات > «SNI spoof (بدون روت)» با IP اتصال، پورت، SNI جعلی، روش، وضعیت موتور و لاگ. تغییرها فوری ذخیره می‌شود.
- **بدون ساخت پروفایل جدا**: هر کانفیگ با سرور `127.0.0.1` و پورت `40443` خودکار از موتور رد می‌شود (همان قاعده‌ی RstaNG).
- **گزینه‌ی «افزودن SNI spoof (بدون روت)»** از منوی افزودن برداشته شد (`SHOW_SNI_SPOOF_NO_ROOT = false`).
- **پینگ واقعی**: برای این کانفیگ‌ها موتور با تنظیمات بالا بالا می‌آید و تأخیر واقعی اندازه‌گیری می‌شود.
- **علت کار نکردن قبلی**: روش پیش‌فرض سرویس `split` بود که روش موتور نیست؛ حالا `combined` است و نام نامعتبر به آن برمی‌گردد. وضعیت و لاگ موتور هم چون در پروسه‌ی دیگر است، با فایل به برنامه می‌رسد.
